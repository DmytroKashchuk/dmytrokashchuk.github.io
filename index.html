publications

  1. Measuring enterprise software supply chain security using public repositories

    Dmytro Kashchuk, Tyler Moore · ACM CCS 2025 — SCORED Workshop

    Large-scale SBOM/CVE study of Forbes Global 2000 GitHub repositories: 11.7% vulnerable dependencies, comparable risk in active vs. inactive projects, and widespread reuse of flawed libraries (semver, Log4j). Releases the largest public dataset to date.

  2. Mind the CORS

    Matteo Golinelli, Elham Arshad, Dmytro Kashchuk, Bruno Crispo · IEEE TPS-ISA 2023

    Large-scale analysis of Cross-Origin Resource Sharing configurations across the Tranco Top 50k websites. Security flaws found in 29.4% of them, including real-world exploitable Denial of Service vectors.
